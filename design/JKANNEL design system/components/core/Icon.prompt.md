The JKANNEL line-icon set (ported from AppIcon.vue) — use for every glyph in nav, topbar, metric tiles and buttons.

```jsx
<Icon name="queue" size={18} />
```

30 names, listed in `ICON_NAMES`: home, sms, queue, check, chevron, server, route, cog, chart, alert, users, api, docker, terminal, plugin, db, shield, search, bell, sun, moon, menu, logout, eye, eyeoff, spark, key, help, external. Icons inherit `currentColor` — set color on the parent, never on the svg.
