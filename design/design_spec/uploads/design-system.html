Design language · v1.0

One language across
Console, Portal & Operations.

A single-accent, airy, hairline-driven system. It favors generous whitespace, tabular numerics for data density, and one decisive Action Blue over decorative color. Everything below is live and theme-aware — toggle dark mode to see every token respond.

Single accent

One Action Blue carries every interactive intent. Color is reserved for meaning, never decoration.

Hairline-driven

Structure comes from 1px hairlines and surface shifts, not heavy borders or drop shadows.

Airy & calm

Generous padding and a restrained type scale keep dense operational data legible.

Numeric-first

Tabular figures everywhere data lives, so columns align and totals are scannable.
