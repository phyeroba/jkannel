# JKANNEL Database Architecture

## Primary Database

PostgreSQL

## Design Principles

-   Normalized schema
-   Foreign-key integrity
-   Auditability
-   Soft deletes where appropriate
-   Indexed search columns
-   Migration-driven evolution

## Major Domains

-   Users
-   Roles
-   SMSCs
-   Routes
-   Messages
-   Queues
-   Delivery Reports
-   Logs
-   Alerts
-   Configuration
-   Audit
