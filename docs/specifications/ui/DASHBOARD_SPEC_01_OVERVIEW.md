# Dashboard Specification - Part 01 - Overview

## Purpose

Provide a real-time operational view of the entire JKANNEL platform.

## Widgets

-   SMS Throughput
-   Active SMSCs
-   Queue Depth
-   Failed Messages
-   DLR Success
-   Engine Health
-   Docker Health
-   CPU
-   Memory
-   Disk
-   Alerts
-   Recent Events

Dashboard refreshes in near real-time using WebSockets/SignalR.
