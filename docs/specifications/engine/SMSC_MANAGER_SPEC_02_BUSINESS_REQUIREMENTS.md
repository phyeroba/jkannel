# SMSC Manager Specification - Part 02 - Business Requirements

## Functional Requirements

-   Unlimited SMSCs
-   Connection templates
-   Connection cloning
-   Bulk enable/disable
-   Import/export definitions
-   Health dashboard
-   Connection grouping
-   Priority ordering
-   Failover groups
-   Throughput limits
-   Retry policies
-   TLS support
-   Configuration validation
-   Dry-run deployment
-   Rollback

## Non Functional Requirements

-   High availability
-   Zero data loss
-   Fast search
-   Audit trail
-   Multi-user support
-   Docker compatible
-   API accessible
-   Extensible

## Acceptance Criteria

An administrator must be capable of deploying a complete SMSC
configuration without editing configuration files manually.
