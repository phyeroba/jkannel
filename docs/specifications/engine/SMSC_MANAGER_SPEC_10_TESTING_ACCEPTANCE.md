# SMSC Manager Specification - Part 10 - Testing & Acceptance

## Unit Tests

-   Configuration validation
-   Credential encryption
-   Adapter selection
-   Connection state transitions

## Integration Tests

-   Deploy to engine
-   Rollback
-   Health polling
-   Metrics collection

## Acceptance Criteria

-   Create SMPP connection
-   Validate successfully
-   Deploy successfully
-   Bind succeeds
-   Health becomes Healthy
-   Rollback restores previous configuration
-   All actions appear in audit log
