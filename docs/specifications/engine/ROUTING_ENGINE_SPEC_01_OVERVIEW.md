# Routing Engine Specification - Part 01 - Overview

## Purpose

The Routing Engine determines how every SMS is delivered.

## Responsibilities

-   Route selection
-   Priority routing
-   Failover routing
-   Prefix routing
-   Customer routing
-   Time-based routing
-   Cost-based routing
-   Load balancing
-   Retry routing

The Routing Engine is independent of the underlying SMS engine.
