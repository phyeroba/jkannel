# Routing Engine Specification - Part 02 - Business Requirements

## Functional Requirements

-   Prefix routing
-   Country routing
-   Operator routing
-   Customer routing
-   Sender ID routing
-   Cost routing
-   Priority routing
-   Time-based routing
-   Load balancing
-   Failover routing
-   Retry routing
-   Blacklist/whitelist routing

## Non-Functional Requirements

-   Deterministic routing
-   High performance
-   Auditability
-   Rule versioning
-   Zero-downtime updates
