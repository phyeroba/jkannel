# Configuration Generator Specification - Part 03 - Configuration Model

## Sources

-   SMSCs
-   Routes
-   Users
-   Throttling
-   Global settings

## Outputs

-   bearerbox.conf
-   smsbox.conf
-   included configuration files

## Rules

Database is the source of truth.

Generated files are never edited manually.

Every generated version receives a unique version number and timestamp.
