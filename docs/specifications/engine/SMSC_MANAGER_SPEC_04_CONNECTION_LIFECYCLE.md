# SMSC Manager Specification - Part 04 - Connection Lifecycle

## Lifecycle

Draft → Validated → Approved → Deployed → Active → Degraded → Disabled →
Archived

## Operations

-   Create
-   Validate
-   Save Draft
-   Deploy
-   Reload Engine
-   Rollback
-   Disable
-   Archive

## Deployment Rules

-   Validate before deploy
-   Keep previous version
-   Record audit trail
-   Allow rollback
-   Health check after deployment
